# Chuja Biryon

Официальный сайт кафе Chuja Biryon в Бохтаре.

Публичный сайт на Next.js, TypeScript, Tailwind CSS и Framer Motion.
Меню хранится статически (`src/data/menu.ts`) и отдаётся через сервисный слой
(`src/services/menu/`). База данных и административная панель не используются.

## Быстрый старт

```bash
npm install
cp .env.example .env.local
# При необходимости заполните переменные в .env.local
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Переменные окружения

Все переменные опциональны — у каждой есть значение по умолчанию.

| Переменная | Описание |
|------------|----------|
| `NEXT_PUBLIC_SITE_URL` | URL сайта (для SEO, sitemap и OG) |
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | WhatsApp номер для кнопок заказа (только цифры) |

## Архитектура меню

```
Public UI (ProductCard, ProductGrid, MenuSection, /menu)
      ↓
src/services/menu/menu-service.ts   — getMenuItems(), getFeaturedMenuItems()
      ↓
src/data/menu.ts                     — статические данные (MenuItem[])
```

Страницы получают опубликованные и отсортированные позиции через сервис и
передают их UI как `MenuItem[]` (`src/types/menu.ts`). Компоненты не импортируют
статический каталог напрямую. Сервис не изменяет исходный массив.

## Ответственность папок

| Папка | Содержимое |
|-------|------------|
| `src/app` | Маршруты, metadata и композиция страниц |
| `src/components/layout` | Общая оболочка, Header, Footer, мобильное меню, логотип и переключатель языка |
| `src/components/sections` | Секции сайта; Menu и Contact также используются на отдельных страницах |
| `src/components/products` | Карточки, фильтры, окно заказа, раскрываемое описание и настройки отображения блюд |
| `src/components/gallery` | Lightbox; состояние выбранного фото принадлежит GallerySection |
| `src/components/shared` | Прикладные компоненты, используемые в нескольких разделах (DeliveryNote) |
| `src/components/ui` | Универсальные кнопки, badges, иконки и заголовки секций |
| `src/components/animations` | Повторно используемая анимация Reveal |
| `src/components/providers` | Контекст языка и синхронизация пользовательского выбора |
| `src/data` | Статический каталог меню и упорядоченный список фотографий галереи |
| `src/constants` | Контакты, карты, пути изображений, доставка, категории и ссылки навигации |
| `src/services/menu` | Получение опубликованных позиций, сортировка и featured-фильтрация |
| `src/hooks` | Активная секция навигации и доступ к языковому контексту |
| `src/i18n` | RU/TJ/EN словари, их контракт и конфигурация локалей (`tg` — код таджикского) |
| `src/types` | Общая модель меню |
| `src/lib` | Чистые функции: варианты блюда, локализованные подписи, WhatsApp-ссылки и форматирование |

Группа маршрутов `(public)` не добавляет сегмент URL: её `page.tsx` обслуживает `/`,
а `layout.tsx` подключает общие Header и Footer. Не создавайте второй `app/page.tsx`.

Список `HOME_FEATURED_SLUGS` остаётся рядом с главной страницей: это её подборка,
а не правило всего каталога. Image-fit presets находятся в
`components/products/product-presentation.ts`; это настройки UI, а не цены или данные блюд.
Порядок и кадрирование галереи меняются в `data/gallery.ts`, переводы подписей — в словарях.

Стили, обработчики прокрутки и модальных окон следует менять отдельными задачами,
проверяя мобильное поведение. Не добавляйте новые слои и barrel-файлы без реального потребителя.

## Деплой на Vercel

1. Подключите репозиторий к Vercel.
2. Добавьте переменные из `.env.example` (опционально).
3. `NEXT_PUBLIC_SITE_URL` — ваш production URL.
4. Deploy.

## Скрипты

- `npm run dev` — разработка
- `npm run build` — production-сборка
- `npm run start` — запуск production
- `npm run lint` — ESLint
